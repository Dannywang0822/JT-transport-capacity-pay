# 极兔河南承运商运费保障平台 · 测试演示

极兔速递河南 · 加盟商运费代扣保障闭环的 **H5/Web 可点击演示**。

这是测试环境静态站，全部为模拟数据，**不接真实结算接口**，不能用于真实扣款或对账。

## 手机 / 线上打开

GitHub Pages（部署完成后可直接用手机浏览器打开）：

https://dannywang0822.github.io/JT-transport-capacity-pay/

首次推送后 Pages 可能需要几分钟才会可访问。页面顶部有「测试环境 · 模拟数据」标识。

## 本地打开

在仓库根目录启动静态服务（不要用 `file://` 直接打开，避免部分浏览器限制脚本）：

```bash
python3 -m http.server 8765 --bind 0.0.0.0
```

浏览器访问：`http://127.0.0.1:8765/`（同一局域网可用本机 IP:8765，手机也可打开）。

## 角色切换

顶部切换：**加盟商端 / 承运商端 / 司机端 / 分拨签收 / 管理后台**

数据保存在浏览器 `localStorage`（键：`jitu_freight_demo_v1`）。左侧「重置数据」可恢复初始模拟状态。

## 推荐演示剧本（约 3 分钟）

1. **加盟商端**：直接使用预置运单 `WB-DEMO-01`（已发布），或再发一条新需求。
2. **承运商端**：对 `WB-DEMO-01` 点「接单锁价」。
3. **司机端**：点「模拟装车扫码 / 上传封签」→ 确认。
4. **分拨签收**：点「模拟电子围栏内签收」→ 再点「结束异议期并首笔代扣 60%」。
5. **承运商端**：在「我的运单」对已进入尾款账期的单点「确认已收尾款」；或切到 **管理后台 → 兜底队列**，对超期单 `WB-HN-0007` 点「触发兜底全额代扣」。
6. **管理后台**：看板 / 代扣记录 / 信用分 查看结果。
